# TourneyManager

Aplicación de escritorio en Java Swing con base de datos SQLite para gestionar equipos, jugadores, torneos de eSports e inscripciones, con la clasificación de cada torneo y el ranking de la temporada. Trabajo Nº2 de Desarrollo de Interfaces (2º DAM).
